# 🏯 Kenshin's Hyprland Dots
> A modern, clean, and developer-focused Arch Linux environment.

This repository contains my personal configuration files (dotfiles) for a highly customized **Hyprland** desktop. Built for productivity, aesthetics, and a seamless development workflow on Arch Linux.

---

## 💻 Tech Stack & Tools

| Category | Selection |
| :--- | :--- |
| **Window Manager** | [Hyprland](https://hyprland.org/) (Wayland) |
| **Status Bar** | [Waybar](https://github.com/Alexays/Waybar) (Customized CSS) |
| **Terminal** | [Kitty](https://sw.kovidgoyal.net/kitty/) |
| **App Launcher** | [Rofi](https://github.com/davatorium/rofi) (Wayland-fork) |
| **Shell** | Bash |
| **Image Viewer** | [Loupe](https://gitlab.gnome.org/GNOME/loupe) (Default) |
| **Notifications** | SwayNC |
| **System Info** | Neofetch |
